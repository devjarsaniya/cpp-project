# MathEngine

MathEngine is a small, production-ready C++17 library for vector and matrix mathematics.
It is designed for Windows developers who want a clean library with runnable examples, tests, and a simple one-command setup.

## Project Overview

This repository contains:

- `include/mathengine/` — public library headers
- `src/` — the library implementation
- `examples/` — demonstration applications
- `tests/` — a CTest-based regression test suite
- `CMakeLists.txt` — cross-platform build configuration

The code supports 3D vectors (`Vector3`) and dynamic matrices (`Matrix`) with expressive operator overloading and safe math operations.

## Features

- `Vector3` arithmetic, dot product, cross product
- Magnitude, normalization, distance, angle, and interpolation
- `Matrix` addition, subtraction, multiplication, transpose, and identity generation
- Bounds-checked row/column access
- Clean console examples and an interactive verifier tool
- CMake-based Windows build workflow with helper scripts

## Requirements

- Windows 10 or later
- CMake 3.16 or newer
- One of these C++ toolchains:
  - MSVC Build Tools
  - MinGW-w64
  - Clang
- PowerShell or Command Prompt

## Quick Start

Open the folder that contains these files:

- `run.bat`
- `README.md`
- `CMakeLists.txt`

Then run:

```bat
run.bat
```

If you downloaded the repository as a ZIP, make sure you open the folder that contains `run.bat`, not the parent folder that only contains a nested directory.

Correct folder example:

```text
MathEngine-main/
└── MathEngine-main/    <-- open this folder
    ├── run.bat
    ├── README.md
    ├── CMakeLists.txt
    └── ...
```

## Build

From the repository root, run:

```bat
build.bat
```

This script:

- detects the installed compiler
- configures CMake with the correct generator
- rebuilds the project

## Run

Execute the verifier tool with:

```bat
run.bat
```

`run.bat` automatically configures, builds, and launches `mathengine_verifier.exe`.

## Test

Run the complete test suite with:

```bat
test.bat
```

This script configures, builds, and executes CTest.

## Clean

Remove generated build files with:

```bat
clean.bat
```

## Troubleshooting

- If the script says CMake is missing, install CMake and restart the terminal.
- If the script cannot detect a compiler, install MSVC Build Tools, MinGW-w64, or Clang.
- If the build directory was created with a different generator, `run.bat` and `build.bat` will now automatically recreate it.
- If you opened the wrong folder, make sure you are in the folder that contains `run.bat`, `README.md`, and `CMakeLists.txt`.

## Common Mistakes

- Opening the outer parent folder after extracting a ZIP archive
- Running `run.bat` from a directory that does not contain `CMakeLists.txt`
- Using a shell without the compiler available in PATH

## Expected Workflow

1. Open the correct project folder where `run.bat` is located.
2. Run `run.bat`.
3. Follow the interactive verifier menu.
4. Run `test.bat` to verify the test suite.
